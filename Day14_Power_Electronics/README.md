# 1️⃣ Voltage Regulator

## Aim
To study the working of a voltage regulator and observe constant output voltage.

## Components Used
DC Power Supply
Voltage Regulator IC (5V / 3.3V)
Breadboard
Connecting Wires
Multimeter

## Working
A voltage regulator maintains a constant output voltage even when input voltage varies.

Example:
Input: 12V–14V
Output: Constant 5V (or 3.3V)

## Observation
When input voltage was increased or decreased, the output remained constant.

## Disadvantage
Excess voltage is converted into heat.
Not efficient for high voltage difference.

# 2️⃣ Half Wave Rectifier

## Aim
To convert AC into pulsating DC using a single diode.

## Components Used
1 Diode
1 Resistor
AC Source (Function Generator)
Oscilloscope

## Working
During positive half cycle → diode conducts.
During negative half cycle → diode blocks current.

Output contains only positive half cycles.

## Disadvantages
Low efficiency
High ripple
Poor DC quality

# 3️⃣ Full Wave Rectifier

## Aim
To convert complete AC signal into pulsating DC.

## Components Used
4 Diodes (Bridge Rectifier)
1 Resistor
AC Source
Multimeter / Oscilloscope

## Working
Both positive and negative half cycles are converted into positive output.
Output frequency becomes double the input frequency.

## Advantage over Half Wave
Higher efficiency
Lower ripple
Better DC output
